MPC-RV is a free, open-source video player with the interface, shortcuts and power tools of MPC-HC. It plays almost any format through mpv and FFmpeg.

Why MPC-RV

Linux has good video players, but none of them is MPC-HC: the full menus, the keyboard shortcuts you already know, and dozens of small tools for subtitles, audio and video. MPC-RV is an MPC-HC alternative for Linux that brings those over, rewritten from scratch in Rust on top of mpv.

Plays almost everything

MKV, MP4, AVI, WebM, MOV, TS, HEVC, AV1, FLAC, Opus and more: anything FFmpeg decodes. Network streams, too, and hardware decoding is one switch away in Options.

MPC-HC's shortcuts

The same default keys as MPC-HC. Every key, mouse button and wheel action can be changed in Options, and media keys work through MPRIS. See all keyboard shortcuts.

A real playlist

Opens and saves MPC playlists (.mpcpl), M3U, PLS and ASX, and plays CUE sheets. Shuffle, repeat, sorting, and "play the next file in the folder".

Subtitle tools

Style overrides, delay, the Subresync bar for fixing timing, and saving as SRT, WebVTT or ASS. Subtitles load automatically, also from subs/ folders.

Audio control

Volume boost up to +300%, normalization, stereo downmix, headphone crossfeed, audio delay, and speed changes with pitch correction.

Video control

Zoom, pan & scan, aspect ratios, rotation, all 22 of MPC-HC's shaders, color management, display sync and frame interpolation.

Discs and devices

DVD and Blu-ray folders and ISO images (titles and chapters), audio CDs, capture cards and webcams, and DVB TV tuners (experimental).

Small things that add up

A-B repeat, favorites, resume where you stopped, thumbnail sheets, screenshots, Go To, and "after playback" actions like shutting down.

42 languages

Menus and Options use MPC-HC's own translations, so the player speaks your language from the start.

Install

MPC-RV runs on any modern Linux distribution. A Windows version is in development.

Flatpak

Ready · any distribution

Download the .flatpak file from the latest release, then:

flatpak install --user mpc-rv-*.flatpak
flatpak run io.github.mpcrv.Player

Arch Linux (AUR)

Coming soon to the AUR

Until then, build the package from the repository:

git clone https://github.com/riflan0ahmed/mpc-revamp.git
cd mpc-revamp/installers/aur
makepkg -si

Questions

Can I run MPC-HC on Linux?

Not natively. MPC-HC is a Windows program, so on Linux it only runs through Wine, a compatibility layer that its developers don't support. MPC-RV is a native Linux player that rebuilds MPC-HC's menus, shortcuts and tools, with mpv doing the playback.

How is MPC-RV different from VLC, mpv or SMPlayer?

All of them play the same formats, because they use FFmpeg. The difference is the interface: VLC has its own menus and shortcuts, mpv is deliberately minimal and keyboard-driven, and SMPlayer offers an MPC-like look. MPC-RV rebuilds MPC-HC itself on top of mpv: its menus, default shortcuts, playlist format, Subresync bar, pan & scan and shaders.

Is MPC-RV the official MPC-HC for Linux?

No. MPC-RV is an unofficial, independent rewrite in Rust, not made by the MPC-HC developers. It aims to give you almost the same experience as MPC-HC on Linux. If you want MPC-HC itself on Windows, get it from clsid2/mpc-hc.

Which video formats does it play?

Almost anything FFmpeg can decode: MKV, MP4, AVI, MOV, WebM, WMV, FLV, TS and M2TS, with H.264, HEVC, VP9, AV1 and older codecs, plus most audio formats. Network streams and DVD and Blu-ray folders work too. DVD and Blu-ray menus aren't supported yet; the titles play directly.

Is it free?

Yes. MPC-RV is free and open source under the GPL-3.0-or-later license, the same license as MPC-HC. There are no ads and no tracking.

Does it work on Windows?

Not yet. A native Windows version, with the Windows 11 look, is in development and shares its core with the Linux app.

How is it made?

MPC-RV is written in Rust, with GTK4 for the interface and mpv for playback. Its code was written with an AI coding assistant, guided and tested by its developer. Bug reports and help from people who know MPC-HC, GTK or mpv are very welcome on GitHub.
